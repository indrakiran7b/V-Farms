# Owner decisions still required

These items are launch blockers or P1 brand facts. The application ships with configurable, clearly labelled placeholders.

## P0 — required before live reservations

1. Permitted event types and maximum attendees.
2. Check-in / check-out times, event hours, and prep/cleanup buffers.
3. Overnight guest capacity and what “whole resort” includes (bedding, linens, all five rooms).
4. Whether any event package includes overnight room access.
5. Stay rates, event deposit schedule, security deposits, cancellation and refund terms.
6. Hospitality, fire, food, music and insurance permissions for Telangana.
7. Razorpay live merchant onboarding, settlement and refund setup.
8. Counsel-approved privacy, stay terms, event terms and tax/GST treatment. Do not hardcode GST.

## P1 — required for a truthful luxury presentation

1. Exact postal address, maps pin, support hours, phone and WhatsApp.
2. Owner-approved photographs of each of the five rooms.
3. Surveyed site plan or drone image for the estate map.
4. Verified amenities and experiences only.
5. Public domain, logo, and media usage rights.
6. Staff accounts and roles (owner, reservations, operations, content).
7. Verified Resend (or other) sending domain.

Development seed rates, capacities and copy are **not** owner-certified.
